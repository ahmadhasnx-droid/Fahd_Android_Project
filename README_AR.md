# مشروع فهد — Fahd AI Studio

مشروع Android أصلي باللغة العربية، مجهز للبناء على GitHub Actions.

## البناء
1. ارفع كامل المشروع إلى مستودع GitHub.
2. افتح Actions.
3. اختر Build Fahd APK.
4. اضغط Run workflow.
5. بعد النجاح نزّل Fahd-debug-apk.

البنية الأساسية: core / features / providers / plugins.
